## What shipped

- Mail API: an organisation's own software can now send email through TatvaOS. Create a key under Organisation → API keys, POST to `/api/v1/mail/send`. Techvein's app is the first user; a PDF integration guide is on the page.
- Each key is tied to chosen sender mailboxes (see item 3 below for the gap).
- API sends, webmail sends and vacation replies work on production again: the API had been knocking on the customer door (587, needs TLS + password) and now uses its own internal door (10587). Postfix restarts on deploy, so the config reaches the running process.
- Every outgoing message now carries a Message-ID on the sender's domain instead of a Docker container ID — Gmail treated the old one as a spam signal on everything we have ever sent.
- Admins have a "reset mailbox password" button; the old "app password" name sent an admin to the wrong reset mid-diagnosis.
- Unverified senders get a proper 550 refusal; Dovecot refuses to start half-configured; Space says when a share list is partial; the deploy workflow can see CI and resets the server to `origin/main` unambiguously.
