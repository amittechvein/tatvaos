## Known risks, named

- **Argon2 primary IMAP passwords**: existing `imap_password_hash` rows are
  raw `$argon2id$` with base64 padding; Dovecot's parser may still refuse
  them even at the ARGON2ID default. **App passwords are immune** ({SSHA512},
  self-prefixed) — which is why the client path uses them. If step 7's wrong-
  password test *accepts* or a real-password login *fails oddly*, tell me;
  the primary-store fix is a follow-up, not a blocker.
- The console page duplicates four settings values from the API's settings
  block, by design (static page). If a port ever changes, change both.
